# Spatio-temporal modelling of Common Tern abundance

This repository contains the R code and dataset used for the analyses presented in the thesis:

"Spatio-temporal Modelling of Ecological Data in RTMB Using the SPDE Approach: An Application to Common Tern Abundance"

## Contents

- 'SpatioTemporal_analysis.R': main script for data preparation, mesh construction, model fitting, and analysis.
- 'Tern_Data.csv': cleaned dataset used in the analyses.

## Main methods

This R code illustrates mesh construction and spde approach in R. It then proceeds to show the process of building a spatio-temporal model and parameter estimation with RTMB. Equation numbers in the code refer to equation numbers in the thesis.
